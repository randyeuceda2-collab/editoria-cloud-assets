\# EditorIA Cloud Assets



Repositorio de almacenamiento y CDN para el motor de edición automatizada \*\*EditorIA\*\*.



\## Estructura

\- `/sfx`: Efectos de sonido breves sincronizados.

\- `/musica`: Pistas de fondo clasificadas por estilo.

\- `/overlays`: Gráficos, transparencias y stickers.

\- `/presets\_fx`: Configuraciones numéricas de animación.

\- `index.json`: Índice semántico para Gemini API.
